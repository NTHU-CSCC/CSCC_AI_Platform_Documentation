    Score a dataset on GPUs with Ray Data¶

    Batch inference is the part of a project nobody budgets for: the model is trained, and now ten million rows need a score. In a workspace that is one GPU working through the whole file. With Ray Data, each GPU worker loads the model once and takes its share of the rows. In the run below, two RTX 5090s scored 10 million rows in 184 seconds, 1.99 times faster than one.

    In this post you score a Parquet dataset with a multilayer perceptron on one GPU, then on two. By the end you have:

    • A Ray Data script that loads the model once per GPU and streams batches through it
    • Inputs, model and scores in your storage, where the next step of your pipeline can read them
    • A measured comparison of one and two GPUs

    The commands and output below come from a run on the platform on 2026-10-04.

    Prerequisites¶

    • Your laptop set up for Ray jobs, as in step 1 of Sweep hyperparameters across GPUs with Ray, with "X-CSCC-GPUs":"2"
    • About 3 GB free in your storage
    • About 15 minutes

    What you'll build¶

    Part Where it runs What it does
    batch_score.py Ray session Creates the data and model the first time, then times one and two GPUs
    Scorer One per GPU worker Loads the weights onto its GPU once and scores each batch with CuPy
    ray-batch/ Your storage input/ (10 million rows, 64 features), mlp-4096.npz, and one scores-* folder per run

    The model is an MLP with three hidden layers of 4,096 units and random weights. Swap in your own model as shown under What you built; the rest stays the same.

    Step 1: Write the script¶

    Save this as batch_score.py in an empty folder:

    """Score a Parquet dataset on GPU workers with Ray Data.

Each GPU worker loads the model once, then scores batches with CuPy.
Inputs and outputs live in your storage.
"""
import argparse
import os
import shutil
import time

import numpy as np
import ray

FEATURES = 64


def make_rows(batch):
    rng = np.random.default_rng(int(batch["id"][0]))
    batch["features"] = rng.standard_normal((len(batch["id"]), FEATURES), dtype=np.float32)
    return batch


def make_model(path, hidden=4096, layers=3, seed=0):
    """Stand-in for your trained model: an MLP with random weights."""
    rng = np.random.default_rng(seed)
    sizes = [FEATURES] + [hidden] * layers + [1]
    np.savez(path, *(rng.standard_normal((a, b), dtype=np.float32) / np.sqrt(a)
                     for a, b in zip(sizes, sizes[1:])))


class Scorer:
    def __init__(self, model_path):
        import cupy as cp
        self.cp = cp
        weights = np.load(model_path)
        self.layers = [cp.asarray(weights[f"arr_{i}"]) for i in range(len(weights.files))]
        gpu = cp.cuda.runtime.getDeviceProperties(0)["name"].decode()
        self.worker = f"{gpu} on node {ray.get_runtime_context().get_node_id()[:8]}"

    def __call__(self, batch):
        cp = self.cp
        h = cp.asarray(batch["features"])
        for w in self.layers[:-1]:
            h = cp.maximum(h @ w, 0)
        score = 1 / (1 + cp.exp(-(h @ self.layers[-1])[:, 0]))
        return {"id": batch["id"], "score": cp.asnumpy(score), "worker": np.full(len(score), self.worker)}


def score(inputs, outputs, model, gpus):
    shutil.rmtree(outputs, ignore_errors=True)
    start = time.time()
    ray.data.read_parquet(inputs).map_batches(
        Scorer, fn_constructor_kwargs={"model_path": model},
        compute=ray.data.ActorPoolStrategy(size=gpus), num_gpus=1, batch_size=50_000,
    ).write_parquet(outputs)
    return time.time() - start


def main():
    p = argparse.ArgumentParser()
    p.add_argument("--data", required=True, help="folder in your storage")
    p.add_argument("--rows", type=int, default=10_000_000)
    p.add_argument("--max-gpus", type=int, default=2)
    args = p.parse_args()
    inputs, model = os.path.join(args.data, "input"), os.path.join(args.data, "mlp-4096.npz")
    if not os.path.exists(inputs):
        ray.data.range(args.rows, override_num_blocks=40).map_batches(make_rows).write_parquet(inputs)
    if not os.path.exists(model):
        make_model(model)

    # Warm-up: start every GPU worker and compile the kernels before timing.
    score(inputs, os.path.join(args.data, "warmup"), model, args.max_gpus)

    for gpus in range(1, args.max_gpus + 1):
        outputs = os.path.join(args.data, f"scores-{gpus}gpu")
        seconds = score(inputs, outputs, model, gpus)
        out = ray.data.read_parquet(outputs)
        rows = out.count()
        print(f"{gpus} GPU: {rows:,} rows in {seconds:.1f} s = {rows / seconds:,.0f} rows/s")
        print(out.groupby("worker").count().to_pandas().to_string(index=False))


if __name__ == "__main__":
    main()

    ① ActorPoolStrategy(size=gpus) with num_gpus=1 starts one Scorer per GPU. Ray Data hands each one batches as it finishes the last, so a slower GPU never holds up the others. ② The model loads in __init__, once per worker, not once per batch. ③ The first score call is a warm-up. It starts both GPU workers before anything is timed, so the comparison measures scoring, not start-up.

    Step 2: Submit the job¶

    ray job submit --working-dir . -- python batch_score.py --data /home/<your username>/ray-batch

    The first run also writes the 10 million input rows (about 3 GB) to your storage. In this run the whole job, warm-up included, took 12 minutes 35 seconds.

    • The two workers split the rows evenly, 5 million each, so throughput doubles.
    • Scaling is this close to linear because the GPU does the work. With a much smaller model, reading and writing Parquet takes longer than the matrix maths, and a second GPU adds nothing: in a trial with one 1,024-unit hidden layer, both runs took about 11 seconds.

    The scores are in /home/<your username>/ray-batch/scores-2gpu/ as Parquet files with id, score and worker columns.

    Step 4: End the session¶

    The session closes after 30 minutes with no job. To release the GPUs now, open the project's Ray tab and select End session under Ray sessions.

    What you built¶

    A batch inference job that keeps one copy of the model on every GPU and spreads the rows across them. To score your own data:

    • Write your rows to Parquet in your storage and point --data at the folder; the script skips creating inputs when input/ exists.
    • Replace make_model and the loop in Scorer.__call__ with your model. Load the weights in __init__.
    • Raise X-CSCC-GPUs and --max-gpus together for more GPUs, then end the session so the next submit starts a new one.
    • If you need PyTorch, ask for it under Requests (details).
