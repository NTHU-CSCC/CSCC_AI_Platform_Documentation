    概念與角色¶

    群組、專案、工作區和儲存空間怎麼搭在一起，以及每個角色能做什麼。

    它們怎麼搭在一起¶

    群組裡有專案。專案用來開工作區、用儲存空間。

    項目 是什麼
    群組 一個團隊或實驗室。有共用的儲存空間，也可以加入多個專案。
    專案 資源放在這裡。有 GPU/CPU 配額、設定檔和部署。
    工作區 在瀏覽器裡用的 JupyterLab 或 VS Code，用專案的配額。
    儲存空間 工作區重啟後檔案還在的磁碟空間。

    配額與資源計畫¶

    管理員會給每個專案一個 資源計畫。你啟動工作區時，平台先檢查專案配額和你自己的配額。

    計畫還會設定：

    • 允許的 GPU 型號：啟動表單只會列出這些。
    • 排程時段（什麼時候能開始工作）和選用的 Burst 時段（什麼時候開放優先佇列）。見下方 計畫時段。
    • 一個或多個你可以選的 佇列，每個佇列有自己的優先級、搶佔與 GPU 型號規則。

    排程佇列、優先級與搶佔¶

    每個工作都要選一個 排程佇列。佇列有優先級，可以設成可被搶佔，也可能有 deserved GPU 數量：

    概念 意義
    優先級 GPU 不夠用時，優先級高的佇列先排。
    可被搶佔 這個佇列裡的工作可能被停掉，把 GPU 讓給優先級更高的佇列。
    Deserved GPU 就算其他佇列來搶，這個佇列也保有的 GPU 數量。0 表示沒有保證，GPU 不夠時最先被讓出去。

    工作區與部署表單會列出專案計畫允許的佇列。預設佇列也要有生效的計畫，而且計畫要允許它。

    計畫時段¶

    計畫有兩組每週時段，都是台灣時間（UTC+8）。

    排程時段 是你能開始工作的時間。時段之外不能送出新工作，優先佇列也一樣，預設佇列也不例外。已經在跑的工作依計畫的停止政策處理。

    Burst 時段 會開放額外的 優先佇列，但排程時段也要開著才有效。Burst 時段留空，就沒有優先時段。

    Burst 時段結束時：

    • 已經結束的工作不受影響。
    • 約 5–6 分鐘後，還在優先佇列上跑的工作不會重新啟動，而是移到計畫中相同 GPU 型號的一般佇列，改用那個佇列的優先級。只有該佇列是 可被搶佔 時，才可能被搶佔。你會收到鈴鐺通知。
    • 計畫裡沒有相同 GPU 型號的一般佇列時，工作會改為停止，你會收到另一則通知。

    排程限制照常適用。

    例如：排程 09:00–18:00、Burst 13:00–15:00。一般佇列 09:00 到 18:00 都能用，優先佇列只有 13:00 到 15:00 能用。儀表板會分別倒數。

    優先權不等於保留

    優先佇列讓你排到隊伍前面，但不會停掉已經在跑的長時間工作。叢集滿載時，你還是可能要等一張卡。

    GPU Claim¶

    你透過 claim 取得 GPU。claim 會寫明：

    • GPU 型號：哪一種 GPU。
    • SM 比例：你能用到這張 GPU 多少算力，用百分比表示。
    • VRAM 模式：elastic 和其他工作共用 GPU 記憶體；hard cap 設嚴格的上限。

    claim 有兩種：

    • inline claim：啟動工作區時自動建立，隨工作區一起消失。
    • 專案 GPU claim：在專案的 GPU Claims 分頁建立，可以在多次部署重複使用。建立當下就會佔用 GPU 配額，但只有工作在用它的時候才累計 GPU 時數。

    專案設定檔用 claim slot（例如 train-a）指向專案 GPU claim。slot 名稱只是標籤，要用你的哪個 claim，在部署對話框裡選。Deployment 的所有 replica 共用同一個 claim，只算一次。只有部分 replica 需要 GPU 的話，請拆成多個 Deployment。

    GPU 時數額度¶

    資源計畫除了上面的 GPU/CPU/記憶體上限，還能限制專案用掉的 GPU 總時間。一個 GPU 時數是一張 GPU 跑一小時，只用到部分張數就按比例算。

    管理員會為每個專案設定額度多久重設一次：預設每月，也可以每週，或每隔固定小時數。專案的 總覽 分頁會顯示你這期用了多少、什麼時候重設。額度用完後，新的 GPU 任務和工作區會被擋下，到重設為止。已經在跑的工作不受影響。

    儲存權限¶

    • 群組儲存空間的權限由群組決定。群組成員一定會拿到這些權限，專案不能改。
    • 專案的儲存頁面會顯示這些權限，但不能在那裡改。
    • 要改群組成員的權限，到群組頁面。不在群組裡的專案成員，到專案頁面設定。專案以外的人不能從專案取得儲存權限。

    關鍵術語¶

    術語 定義
    儲存空間 工作區重啟後檔案還在的磁碟空間
    排程佇列 一組排程規則，決定優先級、搶佔、計畫時段，以及可以用哪些 GPU 型號
    計畫時段 每週你能用的時段（UTC+8）；Burst 時段在這個範圍內另外開放優先佇列
    搶佔 停掉可被搶佔佇列裡的工作，把資源讓給優先級更高的工作
    GPU Claim 你對 GPU 的佔用。專案 claim 建立時就佔用配額，只有工作在用它時才累計 GPU 時數
    GPU 時數 一張 GPU 跑一小時。計畫的 GPU 時數額度是專案在一個週期內（預設每月）最多能用的量
    設定檔 部署的定義。每次儲存都會產生新版本，舊版本不會被改動
    SM 比例 你分到的 GPU 算力百分比
    資源計畫 專案的範本，設定 GPU、CPU、記憶體上限、允許的 GPU 型號與計畫時段
    工作區 在瀏覽器裡用的 JupyterLab 或 VS Code
