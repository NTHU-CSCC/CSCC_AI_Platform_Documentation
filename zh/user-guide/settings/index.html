    設定¶

    在這裡改個人資料和密碼、管理 CLI 用的 API token、設定通知、選介面語言。

    適用對象： 所有登入的使用者。從左側選單的 設定 進入。

    分頁¶

    圖 1：設定頁面的個人資料、安全性、通知、偏好設定分頁。

    分頁 用途
    個人資料 修改全名；查看使用者名稱和電子郵件
    安全性 變更密碼；建立和撤銷 API token；複製 CLI 設定指令
    通知 開關通知；連結 Discord 收私訊
    偏好設定 選擇介面語言

    個人資料¶

    • 全名 — 可以改；所有顯示你名字的地方都會用它
    • 使用者名稱 — 唯讀；你的登入帳號

    • 電子郵件 — 帳號來自帳號目錄時唯讀

    • 開啟 個人資料 分頁。

    • 修改 全名。
    • 點 儲存變更。

    安全性¶

    變更密碼¶

    1. 開啟 安全性 分頁。
    2. 輸入 目前密碼。
    3. 輸入 新密碼（至少 8 個字元）。
    4. 在 確認密碼 再輸入一次新密碼。
    5. 點 變更密碼。

    一組密碼全平台通用

    新密碼所有登入方式都能用，包含 VPN。帳號由外部身分提供者管理的話，請到那邊改密碼。

    API token 與 CLI¶

    要用 cscc-cli，先到 安全性 分頁拿 token。表格列出你有效的 token，有 prefix、上次使用時間和到期時間。

    • 建立 token — 建立新 token，名稱選填。完整的 token 只 顯示一次，關掉對話框前先複製。對話框裡也有一行可以直接貼上的 cscc-cli login --api-url ... --token cscc_... 指令。
    • 撤銷 — 讓 token 失效。用這個 token 的 CLI 下次呼叫就會失敗。

    token 預設 90 天後到期，每個帳號最多 20 個有效 token。

    只顯示一次

    平台不會保存可讀的 token。弄丟了就撤銷，再建立一個新的。

    下載¶

    安全性 分頁的 下載 卡片放著要裝在自己電腦上的檔案，登入後才能下載。

    項目 用途
    Linux、macOS、Windows 版 cscc-cli 命令列工具，已內建平台憑證
    SHA256SUMS 檢查下載的檔案有沒有損壞或被改過
    根憑證 cscc-root-ca.pem，給 ray 這類從你電腦連到平台的 Python 工具用

    cscc-cli 每次發布前都會先掃過已知漏洞。

    通知¶

    兩個核取方塊：

    核取方塊 作用
    推播通知 儀表板內關於你的申請和專案的通知。點 儲存變更 才會生效。
    電子郵件通知 目前只是顯示，不會儲存。會不會寄信，要看平台的郵件設定。

    Discord 私訊¶

    平台開了 Discord 機器人時，這個分頁會有 Discord 私訊 區塊。點 連結 Discord，在 Discord 按同意後會回到這一頁，同時收到一則歡迎私訊。之後鈴鐺的每則通知，機器人都會私訊你，儀表板關著也收得到。例如：

    • 你的工作負載快被搶佔，或已被搶佔
    • 你的任務完成或失敗
    • 工作負載因執行時間上限而停止
    • 突發時段的工作負載轉為正常優先權，或因沒有可用佇列而停止
    • 新公告

    在機器人的私訊裡，/jobs 每頁顯示 10 筆工作，按 Previous、Next 翻頁。輸入 keyword 可以搜尋工作 ID、狀態和佇列名稱，不分大小寫，翻頁時關鍵字會保留。active 只看還在執行的工作；recent 從最近結束的工作開始，可以一直往前翻。/clear 會刪掉機器人傳的一般訊息。標示「只有你看得到」的回覆不會清掉，要自己在 Discord 關閉。

    連結時會順便把你加進平台的 Discord 伺服器，因為機器人只能私訊跟它在同一個伺服器的人。第一則訊息被 Discord 擋掉的話，到 Discord 隱私設定允許伺服器成員私訊，再連結一次。按 取消連結 就不會再收到私訊，儀表板的通知鈴鐺不受影響。

    偏好設定¶

    在 語言 選 English 或 Traditional Chinese，點 儲存，介面馬上切換。

    常見問題¶

    密碼欄位是灰色的。

    你的帳號由外部身分提供者管理，請到那邊改密碼。

    我忘記密碼了。

    登入頁不能重設，請管理員幫你重設。新密碼所有登入方式都能用，包含 VPN。

    電子郵件顯示錯誤。

    電子郵件來自帳號目錄，請管理員幫你更新。

    我可以刪除帳號嗎？

    只有管理員可以。請送一筆申請，說明你的需求。

    API token 不見了，能找回嗎？

    不能。到 安全性 分頁撤銷它，再建立一個新的。
