    使用規範¶

    平台的運算與儲存資源供教學與研究使用。這些規範適用於每一位有帳號的人。平台會記錄操作和存取。各角色能做什麼，見概念與角色。

    帳號與存取安全¶

    1. 帳號限本人使用。不要把帳號、密碼、API token、VPN 設定檔或金鑰給任何人，包含同實驗室的人、同組同學和助教。
    2. 別人也要用資源，就請管理員幫對方開帳號，或把對方加進你的專案或群組。不要共用登入。
    3. 密碼至少 8 個字元，不要和其他服務用同一組。你不能自己重設，忘記密碼請找管理員，新密碼 VPN 也通用。
    4. API token 等同密碼。不要寫進程式碼、Notebook、映像檔或 Git 儲存庫。不用的 token 到 設定 撤銷。
    5. 登入失敗 5 次會鎖 15 分鐘。不要寫腳本反覆試登入。
    6. 只透過 VPN 和 cscc.nthu.edu.tw 的網址使用平台。不要繞過 VPN，也不要直接連其他內部網址或 IP。
    7. 不要冒用別人的身分送申請，也不要更動和你無關的專案或群組。
    8. 如果密碼可能外洩、看到不是你的資料，或收到不是你本人登入的通知，馬上改密碼並通知管理員。
    9. 課程結束、離開實驗室或畢業時，請通知管理員停用你的帳號。

    運算資源使用¶

    1. 資源供教學與研究使用。不要拿來挖礦、破解密碼、當跳板或代理，也不要提供商業服務。
    2. 工作區用完就刪掉。不要為了佔位子讓 GPU 空轉。閒置超過列表下方標示的時間，工作區會自動停止。
    3. GPU 桌面最多用 8 小時，30 分鐘沒人用就會被回收。結束後，只有已掛載儲存空間裡的檔案會留下。
    4. 一個 GPU 時數是一張 GPU 跑一小時，只用到部分張數就按比例算。額度用完後，新的 GPU 任務和工作區會被擋下，執行中的工作不受影響。
    5. GPU claim 一建立就佔用配額，就算還沒有工作在用。不用的請刪掉。
    6. 只申請你真正需要的 GPU 數量和型號。
    7. 用可搶佔的佇列時，工作區可能被優先級更高的工作停掉。把進度存到已掛載的儲存空間，並讓訓練可以接著跑。
    8. 不要繞過配額、時間上限或排程規則，包含自動重啟腳本，以及假裝有人在用來躲過閒置停止。
    9. 需要超出配額的資源，到 申請 送一筆資源申請。

    儲存與資料¶

    1. 只有已掛載的儲存空間會留著：個人儲存空間在 /home/<你的帳號>，群組儲存空間在 /mnt/shared/<儲存空間名稱>。存在其他位置的檔案，工作區停止或刪除後就沒了。
    2. 平台儲存空間沒有備份。重要資料和研究成果，自己另外留一份。
    3. 不要超出配額。用量長條變琥珀色（70%）或紅色（90%）時，先清掉暫存、資料集副本和舊的 checkpoint，再考慮申請擴充。
    4. 不要存與教學研究無關的檔案，例如私人影音、個人備份、盜版軟體或來路不明的資料集。
    5. 群組儲存空間是大家共用的。只動自己的資料夾，不要改或刪別人的檔案。離開群組後，就不能再用那個空間。
    6. 放個資、未公開的資料集或需要保密的資料之前，先確認授權和相關規定，並取得指導老師同意。這類資料不要放進群組儲存空間或映像檔。
    7. 超過 500 MB 的檔案，請在工作區裡用 wget、curl 或 rclone 下載，不要用瀏覽器上傳。
    8. 儲存空間刪除後就救不回來。離開平台前，先把資料搬走。

    映像、軟體授權與對外服務¶

    1. 只用可信來源的映像。平台會自動掃描映像的安全問題。只有映像裡的套件不適合在這裡執行時才會被拒絕，工作會以「blocked by the platform」失敗。你自己 container 內的已知弱點不會擋。
    2. 用到的軟體、模型權重和資料集，都要遵守它們的授權。不要安裝或散布盜版與破解軟體。
    3. 你自己建的映像檔裡，不要放帳號、密碼、token、金鑰或沒有授權的資料。
    4. 專案建的映像只給該專案用。
    5. 不要在平台上對外提供沒經過核准的服務，例如公開網站、檔案分享和代理節點。
    6. 不要掃描、探測或攻擊平台內外的任何主機與服務，包含別人的工作區。
    7. 不要繞過或關掉平台的安全機制和日誌。
    8. 發表研究成果時，依你所屬單位的規定，標註用了本平台的運算資源。

    有疑問時¶

    規範沒寫到的情況，到 申請 送一筆問題回報，或直接問平台管理員。
