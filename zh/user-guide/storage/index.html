    儲存¶

    儲存空間是一個不會跟著工作區消失的資料夾。寫在已掛載儲存空間內的東西，工作區停止或刪除後都還在。

    沒掛儲存空間的工作區什麼都不會留

    個人儲存掛在 /home/<你的帳號>，每個群組儲存空間掛在 /mnt/shared/<儲存空間名稱>。寫在其他位置的檔案，工作區停止、重啟或刪除時就沒了。平台在啟動沒有儲存空間的工作區前會警告你。

    適用對象： 個人儲存由管理員建立，不是每個帳號都有。到 儲存 → 個人 確認，沒有就請管理員建立。群組儲存空間的權限由群組管理員管理，只有現任群組成員能擁有權限。

    儲存類型¶

    個人儲存 群組儲存
    擁有者 你 群組
    由誰建立 管理員 管理員，依申請建立
    誰能用 只有你 群組成員，依權限
    適合 你的資料集、notebook、實驗 共用資料集、團隊協作
    在哪管理 儲存 → 個人 儲存 → 群組

    儲存頁面¶

    圖 1：儲存頁面的個人與群組分頁。

    • 個人 — 你自己的儲存空間
    • 群組 — 你所屬群組的儲存空間

    每個儲存空間顯示名稱、容量（例如 50Gi）、狀態（Available、Bound、Pending）和開啟檔案瀏覽器的按鈕。群組管理員另外會看到 權限。

    儲存空間的生命週期¶

    1. 你在申請頁面提出需求。
    2. 管理員核准並建立儲存空間。
    3. 儲存空間綁定到專案，出現在工作區表單中。
    4. 工作區掛載它，資料在重啟後還在。
    5. 管理員刪除它，儲存空間和資料一起消失。

    刪除無法復原

    刪除儲存空間會銷毀裡面所有內容。申請移除前先備份重要資料。

    瀏覽檔案¶

    1. 在 儲存 → 個人 點 啟動，等檔案瀏覽器就緒。
    2. 點 瀏覽，瀏覽器在新分頁開啟。
    3. 用完點 停止。

    群組儲存空間點 瀏覽檔案。你在該儲存空間的權限是 無 時按鈕不可用。

    圖 2：檔案瀏覽器，可上傳、下載、刪除。

    在瀏覽器裡可以切換資料夾、上傳（拖曳或選檔）、下載檔案與資料夾、建立資料夾、刪除。刪除立即生效。

    大檔案

    超過 500 MB 的檔案，請在工作區內用 wget、curl 或 rclone 下載，不要從瀏覽器上傳；瀏覽器上傳有大小與逾時限制。

    在工作區掛載儲存空間¶

    1. 在 新增工作區 表單展開 儲存 區塊。
    2. 點 + 新增掛載。
    3. 選一個儲存空間。
    4. 設定 掛載路徑（例如 /data）。
    5. 要掛更多就重複。

    掛載路徑固定

    每個工作區都用一樣的掛載路徑，程式才會一直在同一個地方找到資料。

    權限¶

    群組儲存空間對每位使用者有一個權限：

    權限 能做什麼
    讀取 掛載、讀取
    寫入 掛載、讀取、寫入
    無 什麼都不能；無法掛載或瀏覽

    群組管理員設的 無 會蓋過專案或群組原本給的權限；清除後恢復正常。要改權限找群組管理員。群組管理員可在群組的儲存分頁批次修改（見 群組）。

    申請更多儲存空間¶

    群組儲存空間由平台管理員建立，群組管理員沒有這個權限。要新的儲存空間或更多容量：

    1. 到 申請 → + 新增申請。
    2. 類型選 Resource。
    3. 寫出需求：容量、用途、群組名稱。
    4. 點 提交。管理員審核後建立。

    常見問題¶

    儲存空間顯示 Pending，什麼時候能用？

    還在建立，通常不到一分鐘。超過 5 分鐘請找管理員。

    儲存空間滿了，但我找不到大檔案。

    在工作區終端機執行 du -sh /home/<你的帳號>/*。常見原因是隱藏資料夾（.cache、.local）和 notebook 的 checkpoint。

    我看得到群組儲存空間，卻不能瀏覽。

    你至少需要該儲存空間的 讀取 權限。找群組管理員。

    刪除工作區後資料還在嗎？

    在。只有儲存空間本身被刪除時資料才會消失。

    多個工作區可以同時掛同一個儲存空間嗎？

    可以。個人與群組儲存空間都能同時掛在多個工作區。

    我在瀏覽器上傳的檔案沒出現在工作區。

    確認工作區的掛載路徑。儲存空間在啟動時掛載，之後上傳的檔案會立即出現，不用重啟。
