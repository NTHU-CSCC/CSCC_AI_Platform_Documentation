    用 Ray 在多張 GPU 上搜尋參數¶

    八組超參數在工作區一組一組試，GPU 一佔就是好幾個小時。改用 Ray 工作，從筆電把整批參數送出去，平台讓每張 GPU 各跑一組，一起跑。

    這篇用兩張 GPU 搜尋學習率和 L2。做完你會有：

    • 一支讓每組參數各用一張 GPU 的 Ray Tune 程式
    • 從筆電送出、在平台上跑的參數搜尋
    • 每組的結果存在你的儲存空間，並印出最佳組合

    下面的指令和輸出都來自 2026-10-03 在平台上實際跑的一次。

    事前準備¶

    • 能連上 VPN、是某個專案的成員、有一個 API token（設定）
    • 筆電上有 Python 3.10 以上
    • 專案裡有一個允許 2 張 GPU 的佇列
    • 大約 10 分鐘

    會用到什麼¶

    元件 在哪裡跑 做什麼
    ray 指令 你的筆電 上傳資料夾、送出工作、顯示輸出
    Ray 工作階段 平台 第一次送出時啟動，閒置 30 分鐘或到最長時限就結束
    GPU worker 平台 有幾組在跑就開幾個，最多 X-CSCC-GPUs 個
    ray-results/ 你的儲存空間 每組的設定和每個 epoch 的指標

    步驟 1：設定筆電¶

    裝 Ray、讓它信任平台的根憑證，再填你要的資源。每一行的意思見提交工作。

    pip install "ray[default]==2.58.0"
export REQUESTS_CA_BUNDLE=~/Downloads/cscc-root-ca.pem
export SSL_CERT_FILE=~/Downloads/cscc-root-ca.pem
export RAY_JOB_HEADERS='{"Authorization":"Bearer cscc_xxx","X-CSCC-GPUs":"2","X-CSCC-Queue":"<queue>"}'
export RAY_ADDRESS=https://api.cscc.nthu.edu.tw/api/v1/projects/<project id>/ray

    設了 RAY_ADDRESS，ray job 指令就不用再加 --address。方案和佇列允許多種 GPU 型號時，標頭再加上 "X-CSCC-GPU-Model":"<型號>"。

    步驟 2：寫參數搜尋程式¶

    平台的 Ray 映像有 NumPy、CuPy、pandas、Ray Tune 和 Ray Data，沒有 PyTorch，所以模型用 CuPy 寫邏輯斯迴歸（logistic regression）。在空資料夾存成 sweep.py：

    """Sweep learning rate and L2 strength for a logistic-regression model on GPU.

Each trial trains on one GPU with CuPy; Ray Tune runs one trial per GPU worker.
"""
import argparse

import cupy as cp
from ray import tune


def make_data(n=200_000, d=512, seed=0):
    rng = cp.random.default_rng(seed)
    w_true = rng.standard_normal(d, dtype=cp.float32)
    x = rng.standard_normal((n, d), dtype=cp.float32)
    y = (x @ w_true + 0.5 * rng.standard_normal(n, dtype=cp.float32) > 0).astype(cp.float32)
    split = int(n * 0.8)
    return x[:split], y[:split], x[split:], y[split:]


def train(config):
    x, y, xv, yv = make_data()
    w = cp.zeros(x.shape[1], dtype=cp.float32)
    for epoch in range(config["epochs"]):
        p = 1 / (1 + cp.exp(-(x @ w)))
        grad = x.T @ (p - y) / len(y) + config["l2"] * w
        w -= config["lr"] * grad
        acc = float(((xv @ w > 0) == (yv > 0.5)).mean())
        tune.report({"val_acc": acc, "epoch": epoch + 1,
                     "gpu": cp.cuda.runtime.getDeviceProperties(0)["name"].decode()})


if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    parser.add_argument("--out", required=True, help="results folder in your storage")
    args = parser.parse_args()

    tuner = tune.Tuner(
        tune.with_resources(train, {"gpu": 1}),
        param_space={
            "lr": tune.grid_search([0.01, 0.1, 1.0, 5.0]),
            "l2": tune.grid_search([0.0, 0.01]),
            "epochs": 50,
        },
        tune_config=tune.TuneConfig(metric="val_acc", mode="max"),
        run_config=tune.RunConfig(name="lr-l2-sweep", storage_path=args.out),
    )
    results = tuner.fit()
    df = results.get_dataframe()[["config/lr", "config/l2", "val_acc", "gpu"]]
    print(df.sort_values("val_acc", ascending=False).to_string(index=False))
    print("best:", results.get_best_result().config)

    ① tune.with_resources(train, {"gpu": 1})：每組用一張 GPU，有幾組在跑就開幾個 worker。 ② storage_path=args.out：結果寫到儲存空間。叢集一關，它自己的磁碟就清掉了。

    步驟 3：送出工作¶

    ray job submit \
  --working-dir . \
  -- python sweep.py --out /home/<你的使用者名稱>/ray-results

    這次第一次送出後 17 秒工作階段就好了，最久可能要一分鐘。接著指令會一路顯示輸出到工作結束。

    步驟 5：結束工作階段¶

    連續 30 分鐘沒有工作，工作階段會自己關。想馬上釋放 GPU，到專案的 Pod 分頁，在 Ray 工作階段 按 結束工作階段。儲存空間裡的檔案不受影響。

    成果¶

    現在你可以在筆電上改程式，丟到平台的 GPU 一次跑兩組，結果留在儲存空間。換成你自己的工作：

    • 把 make_data 和 train 裡的迴圈換成你的模型，tune.report 留著。
    • 想同時跑更多組：調高 X-CSCC-GPUs（最多 10），再結束工作階段，下次送出才會用新設定。
    • 資料放在儲存空間直接讀；資料夾寫進 .gitignore，才不會跟著上傳（上限 500 MiB）。
    • 要 PyTorch：到 申請 頁申請（細節）。
