    用 config file 在兩張 GPU 上訓練¶

    訓練在 notebook 裡跑通之後，通常不會一直留在 notebook。程式寫好之後，你會希望它自己跑、能用不只一張 GPU、結果也留得下來。Config file 就是做這件事的：幾行 YAML，平台把它排成一個工作，掛上你的儲存空間，給它方案允許的 GPU。下面這次實測，用 PyTorch DistributedDataParallel（DDP）在兩張 RTX 5090 上訓練 ResNet-18，速度是一張的 1.4 倍，準確率一樣。

    這篇用 DDP 在 CIFAR-10 上訓練 ResNet-18，先用一張 GPU，再用兩張。跟著做完，你會有：

    • 一支 DDP 訓練程式，工作分到幾張 GPU 就用幾張
    • 從儀表板部署的 config file，一張和兩張 GPU 各一份
    • 存在儲存空間的 TensorBoard 日誌、模型檔，以及一張 GPU 和兩張 GPU 的實測比較

    文中的指令和輸出，都是 2026-10-04 在平台上實際跑出來的。

    事前準備¶

    • 在某個專案有 管理者 角色，專案裡有能用 2 張 GPU 的佇列
    • 從筆電建置自己的映像建好的 ddp-trainer 映像，或任何裝了 PyTorch 的映像
    • 大約 15 分鐘

    會用到什麼¶

    元件 在哪裡跑 做什麼
    Config file 專案的 配置 分頁 描述工作：映像、指令、CPU、記憶體、GPU、儲存空間
    torchrun 工作的容器 每張 GPU 啟動一個訓練程序
    train_ddp.py 每個程序 各自算每一批資料的一部分，DDP 負責平均梯度
    /workspace 你的儲存空間 CIFAR-10、TensorBoard 日誌、模型檔

    步驟 1：寫訓練程式¶

    上一篇建好的映像裡，這支程式已經放在 /app/train_ddp.py：

    """Train ResNet-18 on CIFAR-10 with DistributedDataParallel.

Launch with torchrun; every process drives one GPU. Rank 0 writes
TensorBoard logs and checkpoints under --out.
"""
import argparse
import os
import time

import torch
import torch.distributed as dist
import torchvision
import torchvision.transforms as T
from torch.nn.parallel import DistributedDataParallel as DDP
from torch.utils.data import DataLoader, DistributedSampler
from torch.utils.tensorboard import SummaryWriter


def loaders(data_dir, batch_size, rank):
    norm = T.Normalize((0.4914, 0.4822, 0.4465), (0.2470, 0.2435, 0.2616))
    train_tf = T.Compose([T.RandomCrop(32, padding=4), T.RandomHorizontalFlip(), T.ToTensor(), norm])
    if rank == 0:  # one download, the other ranks wait at the barrier
        torchvision.datasets.CIFAR10(data_dir, train=True, download=True)
        torchvision.datasets.CIFAR10(data_dir, train=False, download=True)
    dist.barrier()
    train = torchvision.datasets.CIFAR10(data_dir, train=True, transform=train_tf)
    test = torchvision.datasets.CIFAR10(data_dir, train=False, transform=T.Compose([T.ToTensor(), norm]))
    sampler = DistributedSampler(train)
    train_dl = DataLoader(train, batch_size, sampler=sampler, num_workers=6, pin_memory=True, persistent_workers=True)
    test_dl = DataLoader(test, 1000, num_workers=2)
    return train_dl, test_dl, sampler


def accuracy(model, test_dl, device):
    model.eval()
    correct = 0
    with torch.no_grad(), torch.autocast("cuda", dtype=torch.bfloat16):
        for x, y in test_dl:
            correct += (model(x.to(device)).argmax(1) == y.to(device)).sum().item()
    model.train()
    return correct / len(test_dl.dataset)


def main():
    p = argparse.ArgumentParser()
    p.add_argument("--data", required=True)
    p.add_argument("--out", required=True)
    p.add_argument("--epochs", type=int, default=10)
    p.add_argument("--batch-size", type=int, default=256, help="per GPU")
    args = p.parse_args()

    dist.init_process_group("nccl")
    rank, world = dist.get_rank(), dist.get_world_size()
    device = torch.device("cuda", int(os.environ["LOCAL_RANK"]))
    torch.cuda.set_device(device)

    train_dl, test_dl, sampler = loaders(args.data, args.batch_size, rank)
    model = torchvision.models.resnet18(num_classes=10).to(device, memory_format=torch.channels_last)
    model = DDP(model, device_ids=[device.index])
    lr = 0.1 * args.batch_size * world / 256  # linear scaling rule
    opt = torch.optim.SGD(model.parameters(), lr=lr, momentum=0.9, weight_decay=5e-4, nesterov=True)
    sched = torch.optim.lr_scheduler.OneCycleLR(opt, lr, epochs=args.epochs, steps_per_epoch=len(train_dl))
    loss_fn = torch.nn.CrossEntropyLoss()
    writer = SummaryWriter(os.path.join(args.out, f"gpus{world}")) if rank == 0 else None

    for epoch in range(args.epochs):
        sampler.set_epoch(epoch)
        torch.cuda.synchronize()
        start = time.time()
        for x, y in train_dl:
            x = x.to(device, non_blocking=True, memory_format=torch.channels_last)
            y = y.to(device, non_blocking=True)
            with torch.autocast("cuda", dtype=torch.bfloat16):
                loss = loss_fn(model(x), y)
            opt.zero_grad(set_to_none=True)
            loss.backward()
            opt.step()
            sched.step()
        torch.cuda.synchronize()
        seconds = time.time() - start
        if rank == 0:
            acc = accuracy(model.module, test_dl, device)
            imgs = len(train_dl.dataset) / seconds
            writer.add_scalar("train/loss", loss.item(), epoch)
            writer.add_scalar("test/accuracy", acc, epoch)
            writer.add_scalar("throughput/images_per_sec", imgs, epoch)
            print(f"epoch {epoch + 1}/{args.epochs}  loss {loss.item():.3f}  "
                  f"test acc {acc:.3f}  {seconds:.1f}s  {imgs:.0f} img/s", flush=True)
    if rank == 0:
        torch.save(model.module.state_dict(), os.path.join(args.out, f"resnet18-gpus{world}.pt"))
        writer.close()
    dist.destroy_process_group()


if __name__ == "__main__":
    main()

    ① DistributedSampler 讓每個程序拿到不同的一份資料，兩張 GPU 合起來，每個 epoch 每張圖剛好看一次。 ② 學習率跟著 GPU 數放大（0.1 × batch × GPU 數 / 256），因為實際的 batch 也變大了。 ③ 只有 rank 0 下載資料、寫日誌、存模型，其他程序在 dist.barrier() 等它。

    步驟 2：寫 config file¶

    打開 專案 → [你的專案] → 配置，按 新增檔案，貼上下面的內容，存成 ddp-gpus2.yaml：

    apiVersion: batch/v1
kind: Job
metadata:
  name: ddp-resnet18-gpus2
spec:
  backoffLimit: 0
  template:
    metadata:
      labels:
        platform-go/dra-gpu-model: rtx5090
    spec:
      restartPolicy: Never
      containers:
        - name: train
          image: 192.168.110.1:30003/p26000001/ddp-trainer:v1
          command: ["torchrun", "--nproc_per_node=2", "/app/train_ddp.py",
                    "--data", "/workspace/cifar10", "--out", "/workspace/ddp-runs",
                    "--epochs", "15"]
          resources:
            requests:
              cpu: "16"
              memory: 48Gi
              nvidia.com/gpu-dra: "2"
            limits:
              cpu: "16"
              memory: 48Gi
              nvidia.com/gpu-dra: "2"
          volumeMounts:
            - name: storage
              mountPath: /workspace
      volumes:
        - name: storage
          persistentVolumeClaim:
            claimName: "{{userVolume}}"

    ① platform-go/dra-gpu-model 標籤和 nvidia.com/gpu-dra 數量，就是在 資源精靈 選 GPU 型號和張數時它寫進去的兩行。部署對話框從這個標籤讀出 GPU 型號。 ② CPU 和記憶體跟著 GPU 數加倍。每個訓練程序開 6 個讀資料的 worker，兩張 GPU 只給 8 顆 CPU 的話，GPU 會一直在等資料。 ③ {{userVolume}} 把你的個人儲存空間掛在 /workspace，資料和結果在工作結束後都還在。

    一張 GPU 的版本另存成 ddp-gpus1.yaml：名稱改成 ddp-resnet18-gpus1，--nproc_per_node=1、nvidia.com/gpu-dra: "1"，CPU 8 顆、記憶體 24Gi。

    步驟 3：部署¶

    在檔案的版本列按 部署，選佇列後確認。工作會出現在 資源 → Pods，打開它的日誌就能看訓練進度：

    epoch 1/15  loss 1.601  test acc 0.462  2.1s  23773 img/s
epoch 2/15  loss 1.469  test acc 0.506  1.5s  32684 img/s
epoch 3/15  loss 1.008  test acc 0.559  1.5s  33115 img/s
…
epoch 13/15  loss 0.448  test acc 0.803  2.0s  25552 img/s
epoch 14/15  loss 0.411  test acc 0.816  1.6s  30847 img/s
epoch 15/15  loss 0.433  test acc 0.821  1.6s  30897 img/s

    映像第一次啟動前會先掃描已知漏洞，所以第一次會在這一步等幾分鐘，之後就直接啟動。第一次執行也會把 CIFAR-10（170 MB）下載到 /workspace/cifar10。

    步驟 4：比較一張和兩張 GPU¶

    用同樣的方式部署 ddp-gpus1.yaml。兩次都訓練 15 個 epoch：

    GPU 數 訓練時間 每秒張數 測試準確率
    1 35.7 秒 21,230 82.7%
    2 24.9 秒 30,530 82.1%
    • 兩張 GPU 的速度是一張的 1.4 倍，準確率的差距在每次訓練本來就會有的誤差內。
    • 沒有快到 2 倍，是因為 ResNet-18 處理 32×32 的小圖，一步只要幾毫秒。每一步還是要在 CPU 上讀圖、做資料增強，再在 GPU 之間平均梯度，這些成本不會因為多一張 GPU 變少。模型越大、圖越大，每一步花在 GPU 上的時間比例越高，就越接近 2 倍。

    每次訓練都會在 /workspace/ddp-runs/ 底下留一個資料夾（gpus1/、gpus2/），裡面是 TensorBoard 日誌，還有 resnet18-gpus2.pt 這樣的模型檔。在 GPU 桌面看訓練結果會把它們畫出來。

    成果¶

    你用一份 YAML 描述訓練，佇列允許幾張 GPU 就能用幾張，每次的日誌和模型都留在儲存空間。換成你自己的模型：

    • 把 train_ddp.py 的資料集和模型換掉，DistributedSampler、DDP(...) 和 rank 0 的判斷都留著。
    • 要加 GPU，只改 GPU 數、--nproc_per_node，以及 CPU 和記憶體。
    • 工作跑完後，刪掉它的執行個體，列表上那一筆就會移除。/workspace 裡的檔案都還在。
