    從筆電建置自己的映像¶

    平台內建的映像涵蓋了常用框架，但專案做久了，總會需要多裝一個套件、鎖定某個版本，或把自己的程式一起包進去。這些都不用在筆電上裝 Docker。cscc-cli build 把資料夾上傳，平台的建置引擎建好映像，存進專案的私有映像倉庫，config file 直接就能用。

    這篇建置的映像，就是兩張 GPU 訓練和 GPU 桌面那兩篇用的。跟著做完，你會有：

    • 筆電上裝好並登入的 cscc-cli
    • 一個裝好 PyTorch、TensorBoard、Matplotlib 和你的程式的映像，放在專案的映像倉庫
    • 可以直接寫進 config file 的映像位址

    文中的指令和輸出，都是 2026-10-04 在平台上實際跑出來的。

    事前準備¶

    • 連得上 VPN，在某個開了 映像建置權限 的專案裡有 管理者 角色
    • 已經有 API token（在設定建立）
    • 大約 15 分鐘

    會用到什麼¶

    元件 在哪裡跑 做什麼
    cscc-cli 你的筆電 打包資料夾、上傳、即時顯示建置日誌
    建置引擎 平台 執行 Dockerfile；全平台一次建置一個
    專案映像倉庫 平台 存放映像，只有你的專案看得到

    步驟 1：安裝 cscc-cli¶

    登入儀表板，打開 設定 → 安全性 → 下載（說明），下載你系統的檔案。Linux 接著執行：

    chmod +x cscc-cli-linux-amd64
sudo mv cscc-cli-linux-amd64 /usr/local/bin/cscc-cli

    macOS 用 darwin 開頭的檔案；Windows 見安裝。CLI 已經內建平台的憑證。

    用 token 登入，確認身分：

    cscc-cli login --api-url https://api.cscc.nthu.edu.tw --token cscc_...
cscc-cli whoami

    login 會印出 token 存在哪裡，whoami 會印出你的帳號和角色。

    步驟 2：寫 Dockerfile¶

    開一個資料夾，放 Dockerfile 和它要複製的兩支程式：train_ddp.py 和 plot_runs.py。

    ddp-trainer/
├── Dockerfile
├── train_ddp.py
└── plot_runs.py

    FROM pytorch/pytorch:2.14.1-cuda13.0-cudnn9-runtime

# X11 and Tk so the plots can open in a GPU desktop
RUN apt-get update \
 && apt-get upgrade -y \
 && apt-get install -y --no-install-recommends libx11-6 libxext6 libxrender1 libxft2 python3-tk xterm fonts-dejavu-core \
 && rm -rf /var/lib/apt/lists/*
# The image's Python is system-managed (PEP 668)
RUN pip install --no-cache-dir --break-system-packages tensorboard==2.20.0 matplotlib==3.10.7

COPY train_ddp.py plot_runs.py /app/
WORKDIR /app

    ① apt-get upgrade -y 會補上基底映像的安全性更新，映像第一次啟動前的安全檢查就比較不會擋下它。 ② 這個基底映像把 Python 標成系統管理，pip 要加 --break-system-packages。沒加的話，建置會停在 externally-managed-environment。 ③ 套件都要在建置時裝好，執行中的容器沒辦法 apt-get install。

    步驟 3：建置¶

    在資料夾裡執行：

    cscc-cli build --project <專案 ID> --name ddp-trainer --tag v1 .

    這次建置花了 9 分鐘。3 GB 的基底映像在之前的建置已經進了快取；換新的基底映像時，第一次建置還要再下載它。建置引擎閒置時會關掉，所以隔一陣子後的第一次建置，要多等一分鐘左右讓它啟動。

    步驟 4：使用映像¶

    Destination 那一行就是映像位址，寫進 config file 的 image: 欄位：

    image: 192.168.110.1:30003/p26000001/ddp-trainer:v1

    用 config file 在兩張 GPU 上訓練部署的就是這個映像。

    成果¶

    筆電上不用裝 Docker，映像在平台上建好，只有你的專案拉得到。之後：

    • 改了 Dockerfile 就換一個 --tag 重新建置，舊的 tag 留給還在用它的 config file。
    • 建置時要帶的值用 --build-arg KEY=VALUE 傳（說明）。
    • 用 cscc-cli build --follow=false 送出後就能關掉終端機，建置歷史在儀表板上看得到。
